# Service Map

## Cloudflare
- Use for Pages or Workers
- Set env vars in Cloudflare dashboard
- Keep secrets out of Git

## Render
- Use for backend/API service
- Set env vars in Render dashboard
- Keep secrets out of Git

## Oracle
- Use for VM or database layer
- Bootstrap with cloud-init
- Use SSH keys for access

## Linode
- Use for VM host
- Bootstrap with cloud-init
- Add SSH key at creation
